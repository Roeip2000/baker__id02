# פרומט מינימלי ל‑Claude Code — שהפרויקט פשוט יעבוד ויעמוד בדרישות

> פותחים טרמינל בתיקיית הפרויקט, מריצים `claude`, ומדביקים את כל הטקסט שמתחת לקו.

---

אתה עובד על פרויקט גמר של תלמיד כיתה י' בתכנות באינטרנט: אתר ASP.NET **WebForms** (C#, ‎.NET Framework 4.8), עברית RTL, מסד נתונים LocalDB בקובץ `App_Data/Database1.mdf` (טבלה `Users`).

בצע **רק** את 4 השינויים הבאים — זה המינימום ההכרחי כדי שהפרויקט יעבוד, יעמוד בדרישות וייראה נקי. אל תוסיף שום דבר מעבר ואל תיגע בקבצים שלא הוזכרו.

**רמת הקוד:** הכול חייב להישאר ברמה של תלמיד כיתה י' — קוד פשוט, קצר וקריא, עם הערות קצרות בעברית (כמו שכבר קיים בפרויקט). בלי טכניקות מתקדמות, בלי ספריות חיצוניות, ובלי דפוסים מורכבים. שתלמיד יוכל להסביר כל שורה.

## שינוי 1 — ולידציית JavaScript בטפסים (הדרישה החסרה היחידה)

בקובץ `Course/CourseSignup.aspx`:
- הוסף `ClientIDMode="Static"` לשדות `txtUserName`, `txtPassword`.
- בכפתור `btnSubmit` הוסף את התכונה: `OnClientClick="return validateSignup();"`.
- הוסף לפני סגירת ה‑`</asp:Content>` האחרון את הסקריפט (בדיקה פשוטה שהשדות לא ריקים בלבד):
```html
<script type="text/javascript">
    function validateSignup() {
        var user = document.getElementById('txtUserName').value.trim();
        var pass = document.getElementById('txtPassword').value.trim();
        if (user === "" || pass === "") { alert("יש למלא שם משתמש וסיסמה"); return false; }
        return true;
    }
</script>
```

בקובץ `Course/Login.aspx`:
- הוסף `ClientIDMode="Static"` לשדות `txtUserName`, `txtPassword`.
- בכפתור `btnLogin` הוסף: `OnClientClick="return validateLogin();"`.
- הוסף את הסקריפט:
```html
<script type="text/javascript">
    function validateLogin() {
        var user = document.getElementById('txtUserName').value.trim();
        var pass = document.getElementById('txtPassword').value.trim();
        if (user === "" || pass === "") { alert("יש למלא שם משתמש וסיסמה"); return false; }
        return true;
    }
</script>
```
> השאר את ה‑RequiredFieldValidator‑ים הקיימים כמו שהם.

## שינוי 2 — לתקן את דף הבית הריק

בקובץ `Default.aspx` (כרגע ריק), עדכן את `Page_Load` כך שיפנה לדף הבית:
```aspx
<%@ Page Language="C#" AutoEventWireup="true" %>
<script runat="server">
    protected void Page_Load(object sender, EventArgs e)
    {
        Response.Redirect("~/main.aspx");
    }
</script>
```

## שינוי 4 — עיצוב קל ופשוט יותר

הבהר ורכך את המראה בלי לשנות מבנה. בקבצים `MainStyle.css` ו‑`CourseArea.css` בצע החלפה גלובלית (find & replace) של שני שמות הצבעים בלבד:
- `beige` → `#f5f1ea` (רקע בהיר ונקי)
- `brown` → `#a9745b` (חום רך ובהיר יותר)

זה כל השינוי בעיצוב. אל תשנה את מבנה ה‑HTML ואל תיגע בשאר כללי ה‑CSS.

*(אופציונלי, להתאמה מלאה של טבלת הניהול: בקובץ `Admin/Users.aspx` עדכן `BackColor="Brown"` → `BackColor="#a9745b"` ו‑`BackColor="Beige"` → `BackColor="#f5f1ea"`.)*

## אסור לעשות
אל תוסיף שאילתות `UPDATE`/`DELETE`, `Application`, או ספריות חדשות. אל תשנה את מבנה ה‑HTML או את סכמת מסד הנתונים. שמור על השאילתות עם פרמטרים. אל תיגע בקבצים שלא הוזכרו.

בנה את הפרויקט (`msbuild baker__id02.sln /t:Build` או דרך Visual Studio) וודא שאין שגיאות. הרץ ובדוק: דף הבית נפתח; בהרשמה עם שדה ריק קופצת הודעת JavaScript והטופס לא נשלח; הרשמה תקינה נשמרת; התחברות עובדת. דווח סיכום קצר של מה שונה בכל קובץ.
