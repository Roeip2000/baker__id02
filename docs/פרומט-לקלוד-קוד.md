# פרומט מוכן להדבקה ב‑Claude Code

> פותחים טרמינל בתיקיית הפרויקט, מריצים `claude`, ומדביקים את כל הטקסט שמתחת לקו. זהו.

---

אתה עובד על פרויקט גמר של תלמיד כיתה י' בתכנות באינטרנט: אתר בשם "Ido Bakery & Pastry" שכתוב ב‑ASP.NET **WebForms** (C#, ‎.NET Framework 4.8), בעברית עם כיוון RTL, עם מסד נתונים SQL Server LocalDB בקובץ `App_Data/Database1.mdf` (טבלה `Users`).

**המשימה שלך:** בצע את כל השינויים שלמטה כדי להתאים את הפרויקט לדרישות המורה. תחילה **קרא את הקובץ `הנחיה-Claude-Code.md`** שנמצא בתיקיית הפרויקט — הוא מכיל את ההסברים המלאים, דוגמאות הקוד המדויקות וצ'קליסט בדיקה. בצע משימות 1–5 (משימה 6 אופציונלית, רק אם זה לא מסבך).

**עקרון על: פשטות מרבית.** זה פרויקט של כיתה י' — מינימום שינויים, קוד קריא, בלי over‑engineering, בלי לשבור מה שכבר עובד.

תקציר השינויים שעליך לבצע (הפרטים המלאים בקובץ ההנחיה):

1. **ולידציית JavaScript בצד הלקוח (הכי חשוב)** — בקבצים `Course/CourseSignup.aspx` ו‑`Course/Login.aspx`: הוסף פונקציית JS (`validateSignup()` / `validateLogin()`) שבודקת את השדות לפני השליחה (שדות ריקים, אורך סיסמה, תקינות אימייל, שנת לידה מספרית, סימון תקנון). חבר אותה לכפתור עם `OnClientClick="return validateSignup();"`, והוסף `ClientIDMode="Static"` לשדות שה‑JS קורא. השאר את ה‑RequiredFieldValidator‑ים הקיימים.

2. **CheckBox "אישור תקנון"** — בטופס `Course/CourseSignup.aspx`, הוסף `<asp:CheckBox ID="chkTerms" ... Text="אני מאשר את תקנון האתר" />` לפני שורת הכפתור.

3. **טבלת HTML בדף נושא** — בקובץ `Recipes/SimpleMixCakes.aspx`, הפוך את רשימת המרכיבים ל‑`<table>` עם עמודות "מרכיב"/"כמות" וסגנון `style` ישיר על התגית (משתמשים ב‑class `users-grid` שכבר קיים).

4. **תיקון דף הבית הריק** — בקובץ `Default.aspx`, הוסף ב‑`Page_Load` הפניה: `Response.Redirect("~/main.aspx");`.

5. **קישור "ניהול" רק למנהל** — בקבצים `all.Master` + `all.Master.cs`: הפוך את קישור "ניהול" ל‑`<asp:HyperLink ID="lnkAdmin" runat="server" Visible="false">`, וב‑`Page_Load` הצג אותו רק אם `Session["isAdmin"]` הוא true.

6. *(רשות)* ניקוי קוד: מחק מ‑`App_Start/Helper.cs` את המתודות `DoQuery` ו‑`IsExist` שאינן בשימוש.

**אסור לעשות:** אל תוסיף שאילתות `UPDATE`/`DELETE`, `Application` state, Master נוסף, או ספריות JS/CSS חדשות. אל תחזור לשרשור מחרוזות בשאילתות (שמור על פרמטרים). אל תשנה את סכמת מסד הנתונים ואל תמחק נתונים. אל תשנה את מבנה התיקיות.

**בסיום:** בנה את הפרויקט (`msbuild baker__id02.sln /t:Build` או דרך Visual Studio) וודא שאין שגיאות. עבור על צ'קליסט הבדיקה שבקובץ ההנחיה. לבסוף דווח לי סיכום קצר של מה שונה בכל קובץ.

עבוד לפי הסדר, משימה‑משימה, והראה לי את השינויים בכל קובץ תוך כדי.
